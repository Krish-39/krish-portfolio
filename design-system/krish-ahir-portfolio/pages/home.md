# Home Page Overrides

> **PROJECT:** Krish Ahir Portfolio  
> **Page Type:** Single-page recruiter portfolio  
> ⚠️ Rules here **override** `design-system/MASTER.md`. Everything else follows Master.

---

## Layout Overrides

- **Pattern:** Portfolio Grid applied to a **sectioned one-pager**, not a masonry gallery-only site and not Product Demo / video hero.
- **Section order (required):** Hero → About → Featured Projects → More Projects → Technical Skills → Education → Currently Looking For → Beyond the Code → Contact.
- **Hero CTAs:** Primary = View Projects (in-page). Secondary = Download CV. Social = GitHub + LinkedIn. No photo.
- **Featured vs more:** NextFilm, Jaatland, AWS Cloud = large alternating treatments. Remaining six = 1/2/3 column grid that can grow.
- **Beyond the Code:** Professional personal section (cars, driving, systems/web/cloud curiosity). Not informal, not automotive branding.
- **Contact:** Final recruiter CTA (email, LinkedIn, GitHub, CV) plus internship date.

## What this page does not override

Colors, type (Outfit / Work Sans), spacing, radius, motion 2/10, accessibility, and anti-patterns stay on Master.
